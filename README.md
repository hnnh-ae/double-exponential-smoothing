# Double Exponential Smoothing

This repository contains a Jupyter notebook that demonstrates double exponential smoothing for time series forecasting.

The notebook reads data from an Excel file, computes the level, trend, and forecast values, and displays the results in a table and chart.

## How to use

1. Open the notebook in Jupyter or VS Code.
2. Run the library import cell.
3. Provide the Excel file path, sheet name, period column, and actual data column.
4. Enter the alpha and beta values.
5. Run the remaining cells to see the forecast output.
